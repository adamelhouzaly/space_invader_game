# Space Invaders

This is a Space Invaders-style game that I created using HTML, CSS, and JavaScript. The goal is to move your spaceship, shoot the aliens, and stop them before they reach the bottom of the screen.

How to Play

Use your keyboard to control the spaceship:

- Press `A` or the `Left Arrow` key to move left
- Press `D` or the `Right Arrow` key to move right
- Press `Space` to shoot

## Features

- A spaceship that the player can move left and right
- Alien enemies that move across the screen
- Player bullets and enemy bullets
- A score system
- Three lives
- Levels that get harder as you clear the aliens
- Buttons for playing on a phone or tablet
- A restart button if you lose or want to play again

## Project Files

- `index.html` — The main page of the game
- `style.css` — The design, colors, layout, and mobile controls
- `game.js` — The game code, including movement, shooting, enemies, scoring, and levels

## Running the Game

To play the game, download or clone this repository and open `index.html` in a web browser.
